# Level 1 Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A console app (`python -m codeforge`) that turns a Request into code and pytest tests through a LangGraph graph with every node in place, pauses for approval, runs the tests in a subprocess sandbox, and prints an honest report saved to SQLite.

**Architecture:** One LangGraph `StateGraph` over a typed `RunState`. Model nodes call a `StructuredCaller` (Groq in the console, a fake in tests). Every decision is made by pure functions: policy, outcome, report. The sandbox is a separate `python -I -m pytest` process. Runs are stored in SQLite, scoped to the config User.

**Tech Stack:** Python 3.11+, LangGraph (`StateGraph`, `interrupt`, `Command`, `MemorySaver`), langchain-core, langchain-groq (`ChatGroq`), Pydantic v2, pytest, built-in `sqlite3`.

**Spec:** `plans/2026-11-15-02-l1-node-actions.md` (the seven L1 decisions), with `AGENTS.md` and `CONTEXT.md`.

## Global Constraints

- Python **3.11+**. The machine has 3.9.6, so a human must install 3.11+ first (see Task 0).
- Dependencies: `langgraph`, `langchain-core`, `langchain-groq`, `pydantic>=2`; dev: `pytest`. **`langchain-groq` needs the user's agreement** (the bootcamp notebook already uses it). Nothing else.
- Models from config: large `openai/gpt-oss-120b` for every L1 model node; small `openai/gpt-oss-20b` (unused in L1).
- Identity only from config (`CODEFORGE_USER_ID`, `CODEFORGE_ROLE` ∈ {`student`, `instructor`}); missing or invalid → raise, never default.
- Sandbox: `python -I -m pytest`, temp dir, **10 s** timeout, kill the whole process group, env = `PATH` + temp `HOME` only, output cut to the first **10 240** bytes.
- `max_repair_attempts = 0` in config.
- Only pytest exit 0 is reported as "TESTS PASSED".
- Generated code is imported by the tests as `from solution import ...`; the files are `solution.py` and `test_solution.py`.
- Never run generated code outside `sandbox/`. Fixtures use obviously fake values. No CI changes. Don't commit unless the user asks; the commit steps below run only with their go-ahead.
- Vocabulary from `CONTEXT.md` (Request, Run, Execution, Conversation, Serving tier).

## Review Focus

1. **A second Request in the same Conversation** (same `thread_id`) must not inherit the previous Run's code, tests, verdict, approval or outcome. Ingress resets every Run field (test in Task 6).
2. **Approval answers other than "approve"** (empty, `y`, `yes`, `approve it`) reject. Only `answer.strip().lower() == "approve"` approves (tests in Tasks 6 and 7).
3. **Generated code that starts a child process** that outlives the timeout: the whole process group is killed, not just pytest (test in Task 4).
4. **Huge or non-UTF-8 output** is truncated and decoded with `errors="replace"`, without crashing (test in Task 4).
5. **Model-written tests that collect nothing** (pytest exit 5) are never reported as passed (tests in Tasks 2 and 6).

**Interfaces:**
- Consumes: everything from Tasks 0–5.
- Produces:

  - `build_graph(settings: Settings, caller: StructuredCaller, store: RunStore, *, run_tests: Callable[..., ExecutionResult] = run_pytest, checkpointer=None) -> CompiledGraph`.
  - Invocation: `graph.invoke({"raw_text": text}, {"configurable": {"thread_id": conversation_id}})`; resume with `graph.invoke(Command(resume=answer), same_config)`.

- Nodes:
  - `ingress`: mask the text, create a `run_id` (uuid4), **return every Run field reset** (`None` / `[]` / `0`), and save the Run.

  - `policy`: `strictest(evaluate_code_policy(code), evaluate_code_policy(tests))`; deny → `outcome="denied"`.
  - `approval`: `interrupt(payload)`; `approved = str(answer).strip().lower() == "approve"`; otherwise → `outcome="rejected"`.
  - `execute`: `run_tests(code, tests, timeout_s=..., max_output_bytes=...)`, then `attempts += 1`.
  - Repair route after `execute`: to `codegen` only if the outcome is a failure and `attempts <= settings.max_repair_attempts`, else to `report`.
  - `report`: compute the outcome if not set, `serving_tier="primary"`, render the report, save the Run.
- Every conditional edge routes on `outcome`, `kind`, `verdict` or `approved`; never on text.
